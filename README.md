# 🎮 Why Minecraft Ecosystem for Core Java?

Most of my public repositories are focused on the Minecraft ecosystem. While it looks like gaming, it is actually a challenging engineering playground where I honed my low-level Java skills:
* **Confronting high concurrency:** Optimized multi-threaded architectures (Folia framework) to support up to 900+ concurrent players.
* **Performance & Memory tuning:** Deep diving into JVM internals, memory management, and bytecode manipulation.
* **Security & Anti-Cheat:** Built advanced custom obfuscation tools and injection detection mechanisms.

*(Note: Most of my corporate web application and enterprise infrastructure codebases are kept in private repositories for security and legal reasons).*
